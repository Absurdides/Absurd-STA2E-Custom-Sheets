# STA 2E Unified Character Console

A Star Trek Adventures 2E character sheet that prints blank, prints filled, and works as a live tracker during play. Everything is saved in your browser; nothing is sent anywhere.

- **Use it online:** https://absurdides.github.io/Absurd-STA2E-Custom-Sheets/
- **User manual:** https://absurdides.github.io/Absurd-STA2E-Custom-Sheets/manual.html (also opened by the **User Manual** button in the app)
- **Run it locally:** download the folder and open `index.html`.
